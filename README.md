# Projeto de Engenharia de Dados: E-commerce & Logística

Este repositório documenta minha jornada de estudos avançados em SQL e Engenharia de Dados. O objetivo é construir, do zero, a base de dados de um e-commerce, simular a entrada de dados sujos de sistemas externos e aplicar técnicas de transformação, validação e otimização.

## Roteiro de Estudos

O projeto está dividido em módulos, seguindo uma complexidade progressiva:

- [ ] **Módulo 00:** Modelagem de Dados (Diagrama ER)
- [ ] **Módulo 01:** Fundamentos (DDL, DML, Qualidade Inicial)
- [ ] **Módulo 02:** Relacionamentos e Regras de Negócio (Joins, Subqueries)
- [ ] **Módulo 03:** Transformação e SQL Avançado (CTEs, Window Functions)
- [ ] **Módulo 04:** Performance e Tuning (Índices, Planos de Execução)

## Ferramentas Utilizadas
- **Banco de Dados:** PostgreSQL
- **Modelagem:** dbdiagram.io / draw.io
